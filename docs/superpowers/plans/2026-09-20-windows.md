# SysWLANInfo Windows Implementation Plan

**Goal:** Ship a runnable Windows network dashboard with real collection, persisted router profiles, logs and explicit router capabilities.
**Architecture:** .NET core models and services, Windows collector, SQLite storage, shared Razor UI in a MAUI Blazor Hybrid Windows host. Separate platform access from UI for later Android support.
**Tech Stack:** .NET 10, MAUI Blazor Hybrid, Microsoft.Data.Sqlite, Windows PowerShell read-only network APIs.
**Spec:** ../specs/2026-09-20-syswlaninfo-design.md

## Global constraints
- German UI; no fabricated data or password bypass.
- First launch works without router login. Optional one-time access through app-owned session.
- No router settings changed during development without concrete target values.
- No privileged shell commands; use desktop elevation tool only if required.
- Android is a later milestone, not a claim of Windows feature parity.
